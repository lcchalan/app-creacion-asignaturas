# v33.0.5 · Formato aplicado del Plan Docente

La vista previa identifica el formato realmente aplicado usando como fuente principal
el snapshot del documento canónico del Plan Docente. El formato institucional activo
actualmente se mantiene separado y nunca reemplaza el formato de un Plan que ya inició
su proceso de revisión.

Ejemplo: Plan enviado con V2, Administración activa V1 después. La vista y el PDF deben
seguir identificando V2 como formato aplicado; V1 puede mostrarse únicamente como formato
institucional vigente.

No modifica Prisma, base de datos, contenido académico ni cuota de IA.
